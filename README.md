# duet

Локальный инструмент асинхронного ревью работы агента. Агент отдаёт файлы на ревью, ты читаешь их в браузере и оставляешь комментарии, агент получает их сам, правит файлы и отвечает. Ты видишь ровно то, что он поменял. Подробно: `docs/vision.md`.

## Установка

Дай своему агенту (Claude Code или Codex) ссылку на этот репозиторий и попроси установить duet. Обновление — так же.

> **Agent:** to install or update duet, follow [INSTALL.md](INSTALL.md).

Из клона: `./install.sh`.
