# duet

Ревью работы AI-агента в браузере. Читаешь результат, оставляешь замечания и отправляешь их агенту — а сам читаешь дальше, пока он исправляет. Потом смотришь только его правки.

Закончил очередной шаг с Claude Code или Codex? Напиши ему **`duet web`**. Агент сам подготовит материалы и откроет ревью.

## Что в нём удобного

- **Не нужно ждать агента.** Отправляй замечания по мере чтения. Агент получает их, исправляет файлы и отвечает, пока ты продолжаешь ревью. Можно отправлять новые комментарии, пока он работает над предыдущими.
- **Не нужно перечитывать всё.** Видно отличие от исходной или последней принятой тобой версии. Правки по замечаниям можно отдельно посмотреть в окне ответа, принять или отклонить. Ответ открываешь сам, когда удобно.
- **Замечания прямо в тексте.** Выдели нужное место и оставь комментарий. Можно обсуждать целый файл, отвечать в ветке и прикладывать картинки. Видно, что ещё не отправлено, что ждёт и над чем агент работает.
- **Можно править самому.** Редактируй файл прямо в браузере или в своём редакторе: duet подхватит изменения с диска.
- **Код, спеки, планы и любые тексты.** duet работает с материалами, которые передал агент, и не привязан к git или другой системе контроля версий.
- **Читать так, как удобно тебе.** Документ с оформлением или исходник, одна или две колонки, подсветка изменений по словам. Markdown и схемы Mermaid можно читать в готовом виде. Основные действия доступны с клавиатуры; есть русский и английский интерфейс, светлая и тёмная темы.
- **Всё на твоей машине.** Программа и история ревью хранятся локально. Для самого duet не нужны аккаунт и облачный сервис; агентом ты пользуешься как обычно.

## Что считается принятым

Файл принят только тогда, когда ты явно принял его. Если он изменился снова — снова требует проверки. Просмотреть и принять ответ агента ещё не значит принять затронутые файлы.

Отличия, версии, статусы принятия и комментариев контролирует сама программа. От агента зависят две вещи: какие материалы он отправит на проверку и что передаст как их исходное состояние. duet показывает изменения относительно этой исходной версии, а после твоего принятия — относительно принятой.

## Установка

Дай своему агенту (Claude Code или Codex) ссылку на этот репозиторий и попроси установить duet. Обновление — так же.

> **Agent:** to install or update duet, follow [INSTALL.md](INSTALL.md).

Для установки вручную:

```sh
curl -fsSL https://raw.githubusercontent.com/senneco/duet/main/install.sh | sh
```

Есть готовые сборки для macOS и Linux, Intel и ARM. Самостоятельно компилировать не нужно. Установщик ставит команду `duet`, скилл и хуки для установленных Claude Code и Codex. После установки начни новую сессию агента; если Codex попросит довериться хукам duet — разреши.

Из клона: `./install.sh`. Подробности — в [инструкции по установке](INSTALL.md).

## Как пользоваться

1. Работаешь с агентом в чате: обсуждаешь задачу, пишешь план, делаешь очередной шаг.
2. Когда есть что проверить, пишешь `duet web`.
3. Читаешь результат в браузере, оставляешь и отправляешь замечания. Пока агент исправляет, читаешь дальше.
4. Проверяешь правки и принимаешь файлы, которые тебя устраивают.
5. Возвращаешься в чат и решаешь, что дальше: следующий шаг, коммит или публикация.

Так удобно проверять каждый шаг SDD — разработки по спецификации. В новом чате продолжаешь работу, а на следующем ревью смотришь изменения с последнего принятия.

[Подробный пример: от первого ревью до следующего шага →](docs/usage.md)

### Основные клавиши

Клавиши нажимаются по очереди, не одновременно.

| Клавиши | Действие |
| --- | --- |
| Выделить текст, затем `g c` | Оставить комментарий к выделению |
| `Пробел c` | Оставить комментарий ко всему файлу |
| `Пробел s` | Отправить комментарии агенту |
| `Пробел r` | Посмотреть ответ и правки агента |
| `Пробел a` | Принять текущий файл |
| `Пробел e` | Самому отредактировать файл |
