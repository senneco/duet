# Установка и обновления

Согласовано 2026-11-18—19. Пользователь устанавливает duet одной командой,
затем получает уведомления о выпусках и обновляется по явному действию.

## Поведение

1. Публичный установщик скачивает готовую сборку и проверяет SHA-256.
   Для поставок из исходников нужен Go 1.25 или новее.
2. Источник выпуска и команда компилятора сохраняются при установке.
   Повторная установка обновляет скилл и хуки без дублей и сохраняет чужие настройки.
3. Проверка выпуска идёт в фоне при запуске и далее, если с прошлой попытки
   прошли сутки. Ошибка фоновой проверки не блокирует работу и не открывает ошибку.
4. Новый выпуск показывается постоянным уведомлением внизу справа.
   После «Позже» остаётся кнопка в верхней строке.
5. По «Обновить» или `duet update` новый выпуск готовится отдельно.
   Пока идёт подготовка, можно продолжать чтение. `duet update --check` не собирает.
6. Перед переключением каждая известная вкладка подтверждает отсутствие
   открытого редактора, черновика комментария и окна ответа. Неподтвердившая
   вкладка блокирует переключение. Агент не должен работать или ждать доставки
   комментариев. Готовое обновление можно применить следующим нажатием.
7. На время переключения новые действия блокируются, состояние ядра заморожено.
   После перезапуска сохраняются ревью, принятые базы, комментарии и место чтения
   каждой вкладки. При постороннем перезапуске вкладка с черновиком не перезагружается.
8. Ошибки подготовки не меняют установку. Ошибки установки и запуска возвращают
   предыдущие файлы программы и настроек. Журнал позволяет восстановиться после
   прерванной установки. История ревью никогда не восстанавливается из старой копии.
9. Поддерживается только совместимый формат данных (`dataFormat: 1`).
10. Первый переход со старого ядра, которое не умеет проверять вкладки, требует
    сохранить работу и остановить его явно. Последующие обновления используют
    проверку готовности. Старые установки сами не обнаружат новый механизм.

## Поставка

Публичный источник — `release.json` последнего GitHub Release. Файл содержит
`protocol`, `dataFormat`, `version`, полный `revision` и при необходимости
поле `binaries` с SHA-256 сборок для каждой платформы. Сборки скачиваются по
тегу версии. Незавершённый черновик не становится текущим.

Для других поставок установщик может указать локальный помощник `fetch`:
`HELPER [ARGS…] read REFERENCE OUTPUT`. Он только получает файл в новый путь.
Команда компилятора задаётся массивом `compiler`, без shell-интерпретации.
Конкретные интеграции и их адреса хранятся вне публичного репозитория.
Источник не меняется автоматически при ошибке.

## Реализация и проверки

- `updates/`: загрузка, проверка описания, безопасная распаковка, локальная сборка.
- `app/update.go`: команды, фоновые проверки, установка и восстановление.
- `server/update.go`, `core/update.go`: проверка вкладок и заморозка ядра.
- `server/web/js/updates.js`: уведомление, готовность вкладки, защита черновиков.
- `updates/source_test.go`, `app/update_test.go`, `server/update_test.go`:
  сбои загрузки и сборки, подмена контрольной суммы, архивы с выходом из каталога,
  занятость, несколько вкладок, откат и прерванная установка.
- `server/browsertest/updates.mjs`: интерфейс, черновик другой вкладки и отмена.
