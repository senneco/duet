# Веб-клиент: поведение

Записано на шаге 6a (чтение и принятие). Ход обсуждения — в `docs/changes/06a-reading/proposal.md`, вид — макет D `docs/changes/06a-reading/mockups/d-keyboard.html`. Устройство — `server/README.md`, раздел «Веб-клиент». Правила ядра — в `docs/specs/core.md`, адрес и живые обновления — в `docs/specs/server.md`.

## Вид

- Вид — по макету D «Клавиатура»: почти без кнопок, строка состояния внизу (режим, файл, «принято N/M», агент, место в файле, подсказка `␣`), меню `␣` всплывает снизу, документ шрифтом с засечками, метки «было / стало / новое» на полях слева.
- Всё, что про отображение (документ/исходник, одна/две колонки, язык, тема), — сверху справа. В меню `␣` только действия.
- Окончательный вид (панель «Вид», палитры, характер) — шаг 7.

## Список ревью

- По адресу `http://duet.localhost:4848` — все ревью, новые сверху. У каждого: название, когда создано, «принято N из M», агент (не подключён / ждёт / занят / работает), непросмотренный ответ, «принято целиком».
- «Занят» — агент подключён и чем-то занят в чате, но комментарии не берёт. «Работает» — у него есть комментарии «в работе».
- `j`/`k` или стрелки — выбрать ревью, Enter или клик — открыть.

## Ревью: дерево файлов

- Слева дерево: по папкам и алфавиту, папки сначала, папки сворачиваются по клику. Общая для всех файлов часть пути не повторяется; цепочка папок без файлов — одной строкой («server/web/»).
- Значки — по `docs/specs/core.md`, «Файлы в дереве». Агент работает по комментариям к файлу — вместо кружка змейка: шесть точек 2×3, огонёк бежит по часовой стрелке.
- Под открытым файлом — его блоки агента с важностью ⇈ ↑ ↓; клик ведёт к началу блока. Клик по названию открытого файла сворачивает и разворачивает его блоки.

## Открытие ревью

- Ревью сверяется с диском с видимым прогрессом.
- Первым открывается файл, который агент отметил начальным, если его ещё не открывали. Иначе — первый по дереву файл, который ещё не открывали.
- Если владелец уже был в ревью в этом браузере — тот же файл и то же место.
- Открытый файл перестаёт мигать во всех вкладках.

## Файл: отличия «база → текущая»

- Отличия считает ядро, клиент их только рисует.
- **Подсветка.** Светлый фон собирает правку в блок. Тёмным подсвечен текст, которого не было (синий) или который убрали (красный): изменённые слова в строке, а строка или абзац, новые или удалённые целиком, — весь их текст. Так новая строка среди изменённых видна сразу. Удалённое не зачёркивается.
- **Одна или две колонки** — одна настройка для всех файлов, запоминается в браузере (`␣v`). Две колонки: слева база, справа текущая, пустые места заштрихованы. Одна колонка: удалённое и добавленное друг под другом.
- **Документ и исходник.** Markdown (и файлы без расширения — страницы Вики, тикеты) по умолчанию показан документом с подсветкой правок в отрисованном тексте; `␣m` — исходник, выбор запоминается. Код и обычный текст — всегда исходником с номерами строк.
- В документе правка показана единицей «было / стало»: старые и новые блоки (абзацы, пункты, таблицы), которых касается правка. Новые блоки — «новое», удалённые — «удалено». Если в блоке только дописаны слова — один новый блок с пометкой «дописано». Блок кода внутри документа, где поменялись отдельные строки, показан один раз, построчно. Если поменялись только пустые строки — маленькая пометка «добавлена / удалена пустая строка».
- **Подсветка синтаксиса** — в коде и в блоках кода внутри markdown, правки поверх неё заметны.
- **Неизменённый текст.** Документ и обычный текст — целиком. В коде неизменённые куски свёрнуты в «ещё N строк» (вокруг правок по три строки), клик разворачивает. Файл без правок — целиком.
- Пока база — исходная версия от агента, над базой видно «до задачи» и откуда она взята.
- Новый файл без базы и удалённый файл — обычным текстом с надписью «новый файл» / «файл удалён».
- Файл, перешедший в другое ревью, — надпись со ссылкой на то ревью.
- Файл, изменённый на диске, — пометка «изменён на диске». Что делать с этим в интерфейсе — отложено (`docs/later.md`).
- У правого края — карта правок; клик по ней прокручивает файл.

## Принять файл (`␣a`)

- `␣a` или «принять» принимает открытый файл и сразу открывает следующий непринятый по порядку дерева (по кругу). Непринятых нет — файл остаётся открытым, и видно «ревью принято целиком» или что ещё мешает (неотправленные комментарии, вопросы агента, непросмотренный ответ, изменения на диске, агент работает).
- Ядро запретило — duet говорит почему: «есть непросмотренный ответ агента к этому файлу» или «файл изменён на диске в обход duet». Файлы, которых ответ не касается, принимать можно.

## Клавиши

- `j`/`k`, стрелки, PageUp/PageDown — прокрутка; `gg`/`G`, Home/End — в начало и в конец.
- `]c`/`[c` — изменения, `]f`/`[f` — непринятые файлы, `]b`/`[b` — блоки агента.
- `␣` — меню действий; `␣a` — принять; `␣v` — колонки; `␣m` — документ/исходник; `?` — все клавиши; Esc — закрыть.
- Всё, что делается клавишами, можно сделать мышью.

## Тема и язык

- Тема: как macOS (по умолчанию, сразу следует за системой) / тёмная / светлая. Язык: по умолчанию язык системы, переключается RU/EN. Выбор запоминается в браузере.

## Живые обновления и скорость

- Всё, что меняется в ядре, видно сразу; открытый файл обновляется на месте, прокрутка не прыгает.
- Ядро остановлено — «duet не запущен», вкладка подключается сама и остаётся на месте.
- Файл на несколько тысяч строк открывается и прокручивается без заметной задержки.

## Не входит

- Комментарии — шаг 6b. Окно ответа, правки владельца — шаг 6c. Панель «Вид» — шаг 7.
- Записка агента «начните отсюда», действия «взять с диска» / «перезаписать» в интерфейсе — `docs/later.md`.

## Сценарии

Нумерация продолжает `docs/specs/agent-protocol.md` (сценарии до 119).

120. КОГДА владелец открывает `http://duet.localhost:4848`, ТОГДА видит все ревью, новые сверху, с названием, временем создания, «принято N из M», статусом агента, пометкой непросмотренного ответа и «принято целиком».
121. КОГДА владелец открывает ревью впервые, ТОГДА ревью сверяется с диском с видимым прогрессом и открывается файл, который агент отметил начальным, а если его нет — первый по дереву файл, который ещё не открывали.
122. КОГДА владелец возвращается в ревью, в котором уже был в этом браузере, ТОГДА открывается тот же файл на том же месте.
123. КОГДА владелец открыл файл, ТОГДА файл перестаёт мигать в дереве во всех вкладках.
124. КОГДА владелец кликает по папке в дереве, ТОГДА папка сворачивается или разворачивается. КОГДА кликает по названию открытого файла, ТОГДА так же сворачиваются или разворачиваются его блоки.
125. КОГДА владелец кликает по блоку агента или нажимает `]b`/`[b`, ТОГДА файл прокручивается к началу блока.
126. КОГДА владелец переключает одну/две колонки (`␣v`), ТОГДА все файлы во всех ревью показываются так же, и выбор сохраняется после перезагрузки.
127. КОГДА открыт markdown, ТОГДА он показан документом с подсветкой правок. КОГДА владелец нажимает `␣m` или переключатель сверху справа, ТОГДА он показан исходником, и выбор сохраняется.
128. КОГДА открыт код с правками, ТОГДА неизменённые куски свёрнуты в «ещё N строк», вокруг правок видно несколько строк, синтаксис подсвечен. КОГДА владелец кликает по свёрнутому куску, ТОГДА он разворачивается.
129. КОГДА открыт документ или код без правок, ТОГДА он показан целиком.
130. КОГДА база файла — исходная версия от агента, ТОГДА над базой видно «до задачи» и откуда она взята. КОГДА у файла нет базы, ТОГДА он показан целиком обычным текстом с надписью «новый файл».
131. КОГДА владелец нажимает `␣a` и файл можно принять, ТОГДА файл принят и сразу открывается следующий непринятый файл по порядку дерева.
132. КОГДА владелец принял последний непринятый файл, ТОГДА файл остаётся открытым и видно, принято ли ревью целиком или что ещё мешает.
133. КОГДА владелец нажимает `␣a`, а ответ агента касается файла или файл изменён на диске, ТОГДА файл не принимается, и duet говорит почему.
134. КОГДА владелец нажимает `]c`/`[c`, ТОГДА файл прокручивается к следующему или предыдущему изменению. КОГДА нажимает `]f`/`[f`, ТОГДА открывается следующий или предыдущий непринятый файл.
135. КОГДА владелец нажимает `␣`, ТОГДА открывается меню доступных действий с клавишами. КОГДА нажимает `?`, ТОГДА видит список всех клавиш.
136. КОГДА в ядре что-то поменялось, ТОГДА вкладка показывает это сразу, а открытый файл обновляется без прыжка прокрутки.
137. КОГДА тема «как macOS» и система переключила тему, ТОГДА duet сразу переключается тоже.
138. КОГДА владелец выбрал язык, ТОГДА весь интерфейс на этом языке, и выбор сохраняется после перезагрузки.
139. КОГДА открыт файл на несколько тысяч строк, ТОГДА он открывается и прокручивается без заметной задержки.
140. КОГДА среди изменённых строк есть строка, новая целиком, ТОГДА весь её текст подсвечен тёмным, и она отличается от изменённых строк, где тёмным подсвечены только новые слова. Так же для удалённых строк и для абзацев в документе.
141. КОГДА агент работает по комментариям к файлу, ТОГДА вместо кружка у файла бежит по часовой стрелке змейка из шести точек.
