# Шаг 6a: веб-клиент — чтение и принятие

## Зачем

Ядро и агенты готовы, но смотреть ревью пока негде: по адресу duet открывается временная страница. На этом шаге появляется настоящий клиент, в котором можно открыть ревью, прочитать все правки и принять файлы. Комментарии — шаг 6b, окно ответа и правки владельца — шаг 6c. Как всё выглядит (цвета, палитры, характер) — шаг 7. Здесь только поведение и простой аккуратный вид.

## Решения владельца

- Шаг 6 разбит на три: 6a — чтение и принятие, 6b — комментарии, 6c — окно ответа и правки владельца.
- Markdown по умолчанию показывается **документом** (отрисованным), переключается в исходник. Код всегда исходником.
- **Подсветка синтаксиса** в коде — уже на этом шаге.
- Дерево файлов — **по папкам и алфавиту**, папки сворачиваются.
- Неизменённый текст: документ показывается **целиком**, в коде неизменённые куски **свёрнуты**, их можно развернуть.
- Одна или две колонки — одна настройка на всё, запоминается, переключается клавишей.
- Прокрутка — `j`/`k` и обычными стрелками.
- После `␣a` duet **сразу переходит** к следующему непринятому файлу.
- Блоки агента — только навигация. Клик по названию открытого файла сворачивает его блоки, как папку.
- Тема и язык — простой переключатель. Панель «Вид» — шаг 7.
- **Вид — макет D «Клавиатура»** (`mockups/d-keyboard.html`, задание — `mockups/BRIEF.md`): почти без кнопок, строка состояния внизу, меню `␣` всплывает снизу, документ шрифтом с засечками, «было / стало / новое» на полях слева.
- Всё, что про отображение (документ/исходник, одна/две колонки, язык, тема), — **сверху справа**. В меню `␣` только действия.
- Агент работает по комментариям — вместо кружка файла **змейка**: шесть точек 2×3, огонёк бежит по часовой стрелке, как обычный индикатор загрузки.
- **Записки агента нет.** Агент отмечает файл, с которого начать, и ревью сразу открывается на нём.
- **Тёмная подсветка — это текст, которого не было (или который убрали).** Светлый фон только собирает правку в блок. Строка или абзац, новые целиком, подсвечены тёмным целиком, иначе новую строку среди изменённых не отличить.

## Что входит

### Список ревью

- По адресу `http://duet.localhost:4848` — все ревью, новые сверху.
- У каждого ревью: название, когда создано, «принято N из M», агент (не подключён / ждёт / работает), есть ли непросмотренный ответ, «принято целиком».
- Клик по ревью открывает его по адресу `/r/<ревью>`.
- Список обновляется сам.

### Ревью: дерево файлов

- Слева дерево файлов ревью: по папкам и алфавиту, папки сворачиваются по клику. Общая для всех файлов часть пути не повторяется в каждой строке.
- Над деревом — название ревью, «принято N из M» и статус агента: не подключён / ждёт / работает / останавливается, а также «агент пропал посреди работы».
- Значки файлов — по `docs/specs/core.md`, «Файлы в дереве»: не открывали (мигающий кружок), открывали (пустой кружок), принят (галочка), агент работает по комментариям (змейка 2×3 вместо кружка, бежит по часовой стрелке), непросмотренный ответ (рябь), удалён (серый), перешёл в другое ревью, изменён на диске.
- Под открытым файлом — его блоки агента с важностью ⇈ ↑ ↓. Клик по блоку ведёт к его началу. Клик по названию открытого файла сворачивает и разворачивает его блоки.

### Открытие ревью

- Ревью сверяется с диском с видимым прогрессом (как на шаге 5e).
- Первым открывается файл, который агент отметил как начальный, если его ещё не открывали. Иначе — первый по дереву файл, который ещё не открывали.
- Агент отмечает начальный файл, когда отдаёт ревью (дополнение к протоколу агента; в скилле — «отметь файл, с которого владельцу начать»). Записки «начните отсюда» больше нет.
- Если владелец уже был в этом ревью в этом браузере, открывается тот файл и то место, где он остановился.
- Файл, который владелец открыл, перестаёт мигать (ядро помечает его открытым).

### Файл: отличия «база → текущая»

- Справа — открытый файл с отличиями «база → текущая», которые посчитало ядро. Клиент ничего не пересчитывает.
- **Подсветка.** Светлый фон собирает правку в блок. Тёмным подсвечен текст, которого не было (синий) или который убрали (красный): изменённые слова внутри строки, а строка или абзац, новые или удалённые целиком, — весь их текст. Так новая строка среди изменённых видна сразу.
- Новый файл без базы и удалённый файл показаны обычным текстом с надписью «новый файл» / «файл удалён», без сплошной подсветки.
- Одна или две колонки — одна настройка для всех файлов и ревью, запоминается в браузере. Переключатель — сверху справа (`␣v`).
  - Две колонки: слева база, справа текущая, пустые места заштрихованы.
  - Одна колонка: удалённое и добавленное друг под другом, изменённые слова подсвечены внутри строки.
- **Документ и исходник.** Markdown по умолчанию показан документом: заголовки, списки, таблицы, ссылки, блоки кода, с подсветкой правок внутри отрисованного текста. Переключается в исходник сверху справа или `␣m`; выбор запоминается в браузере. Код и обычный текст — всегда исходником.
- **Подсветка синтаксиса** в исходнике кода и в блоках кода внутри markdown. Подсветка правок поверх неё остаётся заметной.
- **Неизменённый текст.** Документ и обычный текст показаны целиком. В коде неизменённые куски длиннее нескольких строк свёрнуты в строку «ещё N строк», вокруг правок остаётся по несколько строк. Клик по свёрнутому куску разворачивает его. Если в файле нет ни одной правки, он показан целиком.
- **Пометка «до задачи».** Пока база — исходная версия от агента, над базой видно «до задачи» и откуда она взята («из git, HEAD» и т. п.).
- Файл, который перешёл в другое ревью, — надпись «перешёл в ревью „…“» со ссылкой на то ревью.
- Файл изменён на диске — видна пометка «изменён на диске». Что с этим делать в интерфейсе, владелец решит позже (см. `docs/later.md`).
- Номера строк видны в исходнике.

### Принять файл (`␣a`)

- `␣a` или кнопка «Принять» принимает открытый файл, и duet сразу открывает следующий непринятый файл по порядку дерева (после последнего — снова с начала). Если непринятых не осталось, файл остаётся открытым, и видно «принято целиком» или что ещё мешает (неотправленные комментарии, вопросы агента).
- Если ядро запрещает принятие, duet показывает почему, на языке интерфейса:
  - есть непросмотренный ответ, который касается файла, — «Есть непросмотренный ответ агента» (кнопка «Открыть» появится на шаге 6c);
  - файл изменён на диске — «Файл изменён на диске в обход duet».
- Принять файл можно, даже если непросмотренный ответ касается других файлов: запрет только для файлов, которых ответ коснулся.

### Клавиши

- `j`/`k` и стрелки вверх/вниз — прокрутка. `gg`/`G` — в начало и в конец файла.
- `]c`/`[c` — следующее и предыдущее изменение в файле.
- `]f`/`[f` — следующий и предыдущий непринятый файл.
- `]b`/`[b` — следующий и предыдущий блок агента.
- `␣` — меню действий с подсказками клавиш (всплывает снизу): `a` — принять файл; серым — то, что появится на шагах 6b и 6c. Esc закрывает меню.
- `␣v` — одна/две колонки, `␣m` — документ/исходник. Это вид, поэтому в меню их нет: они показаны сверху справа с подписанными клавишами.
- `?` — список всех клавиш.
- Всё, что делается клавишами, можно сделать и мышью.

### Тема и язык

- Тема: как macOS (по умолчанию) / тёмная / светлая. Язык: по умолчанию язык системы (русский, если система на русском, иначе английский), переключается на английский или русский. Переключатели сверху справа, рядом с видом; выбор запоминается в браузере.
- В теме «как macOS» duet сразу следует за сменой темы системы.

### Живые обновления

- Всё, что меняется в ядре, видно сразу (как на шаге 5e). Открытый файл обновляется на месте: прокрутка не прыгает.
- Ядро остановлено — видно «duet не запущен», вкладка подключается сама и остаётся на том же месте.

### Скорость

- Ревью и файл открываются без заметной задержки, в том числе файл на несколько тысяч строк.

## Что не входит

- Комментарии: выделение, `gc`, `␣c`, карточки, `␣s`, «прервать» — шаг 6b.
- Окно ответа и подсказка `␣r`, правки владельца (`␣e`, «вернуть к базе») — шаг 6c.
- «Изменён на диске» в интерфейсе: плашка, «взять с диска», «перезаписать» — отложено на продумывание (`docs/later.md`).
- Панель «Вид» (характер, палитры, края текста, шрифты), «фокус по блокам» — шаг 7.
- Записка агента «начните отсюда» — убрана (в `docs/later.md`).
- Временная страница `server/web/index.html` заменяется клиентом.

## Сценарии

Нумерация продолжает `docs/specs/agent-protocol.md` (сценарии до 119).

120. КОГДА владелец открывает `http://duet.localhost:4848`, ТОГДА видит все ревью, новые сверху, с названием, временем создания, «принято N из M», статусом агента, пометкой непросмотренного ответа и «принято целиком».
121. КОГДА владелец открывает ревью впервые, ТОГДА ревью сверяется с диском с видимым прогрессом и открывается файл, который агент отметил как начальный, а если его нет — первый по дереву файл, который ещё не открывали.
122. КОГДА владелец возвращается в ревью, в котором уже был в этом браузере, ТОГДА открывается тот же файл на том же месте.
123. КОГДА владелец открыл файл, ТОГДА файл перестаёт мигать в дереве во всех вкладках.
124. КОГДА владелец кликает по папке в дереве, ТОГДА папка сворачивается или разворачивается. КОГДА кликает по названию открытого файла, ТОГДА так же сворачиваются или разворачиваются его блоки.
125. КОГДА владелец кликает по блоку агента или нажимает `]b`/`[b`, ТОГДА файл прокручивается к началу блока.
126. КОГДА владелец переключает одну/две колонки (`␣v`), ТОГДА все файлы во всех ревью показываются так же, и выбор сохраняется после перезагрузки.
127. КОГДА открыт markdown, ТОГДА он показан документом с подсветкой правок. КОГДА владелец нажимает `␣m` или переключатель сверху справа, ТОГДА он показан исходником, и выбор сохраняется.
128. КОГДА открыт код с правками, ТОГДА неизменённые куски свёрнуты в «ещё N строк», вокруг правок видно несколько строк, синтаксис подсвечен. КОГДА владелец кликает по свёрнутому куску, ТОГДА он разворачивается.
129. КОГДА открыт документ или код без правок, ТОГДА он показан целиком.
130. КОГДА база файла — исходная версия от агента, ТОГДА над базой видно «до задачи» и откуда она взята. КОГДА у файла нет базы, ТОГДА он показан целиком обычным текстом с надписью «новый файл».
131. КОГДА владелец нажимает `␣a` и файл можно принять, ТОГДА файл принят (галочка) и сразу открывается следующий непринятый файл по порядку дерева.
132. КОГДА владелец принял последний непринятый файл, ТОГДА файл остаётся открытым и видно, принято ли ревью целиком или что ещё мешает.
133. КОГДА владелец нажимает `␣a`, а ответ агента касается файла или файл изменён на диске, ТОГДА файл не принимается, и duet говорит почему.
134. КОГДА владелец нажимает `]c`/`[c`, ТОГДА файл прокручивается к следующему или предыдущему изменению. КОГДА нажимает `]f`/`[f`, ТОГДА открывается следующий или предыдущий непринятый файл.
135. КОГДА владелец нажимает `␣`, ТОГДА открывается меню доступных действий с клавишами. КОГДА нажимает `?`, ТОГДА видит список всех клавиш.
136. КОГДА в ядре что-то поменялось (агент прислал файлы, действие в другой вкладке, подключился агент), ТОГДА вкладка показывает это сразу, а открытый файл обновляется без прыжка прокрутки.
137. КОГДА тема «как macOS» и система переключила тему, ТОГДА duet сразу переключается тоже.
138. КОГДА владелец выбрал язык, ТОГДА весь интерфейс на этом языке, и выбор сохраняется после перезагрузки.
139. КОГДА открыт файл на несколько тысяч строк, ТОГДА он открывается и прокручивается без заметной задержки.
140. КОГДА среди изменённых строк есть строка, новая целиком, ТОГДА весь её текст подсвечен тёмным, и она отличается от изменённых строк, где тёмным подсвечены только новые слова. Так же для удалённых строк и для абзацев в документе.
141. КОГДА агент работает по комментариям к файлу, ТОГДА вместо кружка у файла бежит по часовой стрелке змейка из шести точек.
