# 7p8. Продолжение ревью после правок

После правок в pull request владелец открывает текущее ревью и продолжает читать с того места, до которого дошёл. Поиск старых ревью и восстановление состояния выполняет duet.

## Сценарии

- КОГДА в текущем ревью появляется файл из прежнего ревью той же рабочей копии, ТОГДА здесь доступны его версии, последняя явно принятая версия и комментарии вместе с ответами и их статусами. Уже просмотренный файл сохраняет отметку об открытии.
- КОГДА текущий текст совпадает с явно принятым, ТОГДА файл остаётся принятым. После правок видны отличия от принятой версии, и файл снова ждёт принятия.
- КОГДА старая запись содержит исходный текст, но по ней нельзя установить, нажимал ли владелец «Принять», ТОГДА файл доступен для обычного ревью и ждёт явного принятия. История сохраняется. Остальные файлы можно ревьюить обычным порядком.
- КОГДА по файлу остались комментарии или непросмотренный ответ, ТОГДА их можно прочитать и продолжить обсуждать в текущем ревью. Переход между ревью сам по себе ничего не принимает, не отклоняет и не отправляет. Повторное открытие сохраняет результат без дубликатов.
- КОГДА файл действительно занят прямо сейчас или duet не смог прочитать изменение, ТОГДА он показывает в текущем ревью конкретный файл или операцию, причину и доступное действие. Сообщение о принятии всего ревью требует успешной проверки изменений.

## Границы

Изменение относится к общим командам и ядру duet, включая уже сохранённые ревью. Рабочий pull request и его файлы для исправления менять не требуется. Для проверки используются изолированные ревью, в том числе со старым форматом данных.

## Проверка

- При загрузке сохранённого ревью предупреждение о старом исходнике снимается. Независимая ошибка чтения остаётся видимой. Доступный файл принимается обычной кнопкой.
- Тест с двумя непросмотренными ответами переносит один из двух файлов прежнего ответа. После перезапуска в текущем окне видны правки и комментарий к выделению. Принятие и отклонение в каждом ревью действует на его файлы.
- После коммита файл с открытой веткой переходит в текущее ревью. Повторные проверки обоих ревью сохраняют одну копию и прежнюю отметку об открытии.
- В Chrome проверены открытие перенесённого ответа, чтение реплики, принятие ответа и отдельное принятие файла. При занятом файле и при ошибке чтения в предупреждении видны конкретные причины.
