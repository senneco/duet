# Версионные выпуски и обновления

Владелец решил выпустить версионные архивы и уведомление об обновлении одним
коммитом. Публичные установки скачивают готовые сборки для macOS и Linux.
Установка и обновление проверяют SHA-256. Переключение ждёт завершения
работы агентов и сохранения черновиков. Локальная сборка остаётся доступной
для поставок с собственной конфигурацией.

Внешняя поставка использует GitHub; дополнительные поставки подключаются
локальным помощником и могут задавать команду компилятора. Детали конкретных
сторонних систем находятся вне этого репозитория.

Публикация — отдельное поручение. В рамках разработки используются временные
данные и установки. Действующая пользовательская программа не заменяется.

## Проверено локально

2026-11-19: полный набор тестов и vet на минимальном Go 1.25.0; полный набор
на Go 1.27.1; race для app, server и updates; 35 тестов клиента. Сборка проходит
для macOS и Linux, arm64 и amd64. Исполнение проверено на macOS; Linux проверит CI.

В Chrome проверены постоянное уведомление, «Позже» и возврат, чтение при сборке,
черновик другой вкладки и отмена переключения. Настоящий отдельный процесс
прошёл загрузку локального тестового выпуска, сборку, ожидание завершения агента
и применение по повторному нажатию. Версия и отпечаток сервера сменились;
принятая база, текст и позиция прокрутки сохранились. Изолированные тесты
проверяют ошибки скачивания, сборки, установки и запуска, откат и журнал.

Публичный выпуск публикуется по тегу. Workflow публикует готовые сборки, архивы и описание выпуска одновременно.
