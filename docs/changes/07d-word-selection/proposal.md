# Выделение по словам и копирование

## Проблема

Воспроизведено в Chrome: второе нажатие начинает обычное выделение по символам. После протягивания обработчик dblclick заменяет весь диапазон словом под курсором в момент отпускания. При копировании в буфер попадает только это последнее слово.

## Поведение

- КОГДА пользователь дважды нажимает на слово, ТОГДА сразу при втором нажатии выделяется целое слово.
- КОГДА после второго нажатия пользователь держит кнопку и ведёт мышь, ТОГДА выделение расширяется целыми словами от исходного слова в обе стороны, в том числе через строки и встроенную разметку.
- КОГДА пользователь отпускает кнопку, ТОГДА выделенный диапазон сохраняется и не заменяется последним словом.
- КОГДА пользователь копирует через Ctrl+C или ⌘C, ТОГДА в буфер попадает весь выделенный текст. В редакторе и поле комментария копируется их собственное выделение.
- Обычное протягивание по символам, комментарии к выделению и отсутствие всплывающих плашек браузера сохраняются.

## Проверка

Автоматическая проверка в Chrome: двойное нажатие без движения, движение вперёд и назад по словам, смена направления, перенос строки, разметка внутри слова, копирование и обычное выделение по символам.

## Границы

Не меняем внешний вид выделения и поведение принятия ответов. Полная замена системы выделения нужна только если текущее устройство не позволит выполнить эти сценарии.

Ctrl+C и ⌘C проверены чтением реального буфера обмена. Копирование textarea не перехватывается. 32 теста клиента прошли.
