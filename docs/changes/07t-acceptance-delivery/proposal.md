# 7t. Передача результата ревью агенту

После принятия последнего файла окно показывает, завершено ли ревью и можно ли возвращаться к агенту за продолжением.

## Сценарии

- КОГДА все файлы приняты, но есть неотправленные комментарии, ТОГДА окно показывает «Все файлы приняты» и число неотправленных комментариев. Ревью остаётся открытым, уведомление о полном принятии не отправляется.
- КОГДА ревью принято целиком и результат ждёт передачи подключённому агенту, ТОГДА под заголовком «Ревью принято целиком» видны обычная крутилка duet и строка «Передаём результат агенту…».
- КОГДА сессия агента получает результат, ТОГДА крутилка исчезает, а в том же окне появляется «Результат передан агенту».
- КОГДА подключённой сессии нет, ТОГДА окно показывает «Агент не подключён» без крутилки.
- КОГДА до передачи снова появляется препятствие для полного принятия, ТОГДА окно обновляется и показывает актуальное состояние ревью.

Эта отметка относится к получению уведомления сессией. Ответ агента в чате может появиться позже.


## Проверка

- Ядро проверяет, что неотправленное замечание снимает полное принятие и статус передачи. Служба доставки проверяет переход после подтверждения очереди, повтор при её ошибке и выдачу без дублирования через хук.
- В Chrome с тестовой сессией проверены крутилка дольше шести секунд, смена статуса после доставки, неотправленные комментарии до и после принятия и отключённая сессия.
