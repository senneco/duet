# Шаг 7l: ответ к принятым файлам сразу в основном просмотре

## Зачем

Если затронутые файлы уже приняты, основной дифф показывает ровно изменения ответа. Отдельный просмотр того же диффа в окне ответа заставляет принимать одну работу дважды.

## Согласованное поведение

Ответ сразу становится текущей версией, если все затронутые им файлы были приняты перед применением ответа. Затронуты как файлы с правками, так и файлы, на комментарии которых агент ответил. Другие файлы ревью на выбор пути не влияют.

База не меняется. Изменённые файлы требуют обычного принятия в основном просмотре. Ответы на комментарии также требуют принятия файла; вопросы остаются открытыми.

Если хотя бы один затронутый файл не принят или новый, весь ответ остаётся в существующем окне ответа. Принятие в этом окне всегда означает только перенос версий вправо, никогда — принятие файла.

## Входит

- Выбор пути в ядре для всего ответа целиком.
- Сохранение истории ответа и привязки комментариев при прямом переносе.
- Доступность новых ответов на комментарии в основном просмотре до принятия файла.
- Автоматические проверки сценариев и проверка интерфейса в браузере.

## Не входит

- Разделение одного ответа между окном и основным просмотром.
- Автоматическое принятие файлов или изменение базы.
- Изменение смысла кнопки «принять ответ».
- Автоматическое переключение открытого файла или места чтения при поступлении ответа.

## Сценарии

1. КОГДА все затронутые ответом файлы приняты, ТОГДА версии ответа сразу становятся текущими, база остаётся прежней, непросмотренного модального ответа нет.
2. КОГДА в ревью есть другие непринятые файлы, которых ответ не касается, ТОГДА они не препятствуют прямому переносу.
3. КОГДА ответ касается принятого и непринятого файла, ТОГДА весь ответ проходит через окно ответа.
4. КОГДА ответ добавляет новый файл, ТОГДА весь ответ проходит через окно ответа.
5. КОГДА ответ удаляет принятый файл, ТОГДА удаление сразу видно в основном диффе и требует принятия файла.
6. КОГДА агент только ответил на комментарий принятого файла, ТОГДА ответ виден в основном просмотре, файл требует принятия; вопрос агента остаётся открытым.
7. КОГДА владелец принимает файл после прямого переноса, ТОГДА текущая версия становится базой и отвеченные комментарии решаются обычным способом.
8. КОГДА уже есть непросмотренный ответ и агент прислал продолжение, ТОГДА продолжение вливается в существующий ответ без автоматического переноса в основной просмотр.
9. КОГДА после прямого переноса агент прислал ещё изменения к теперь непринятому файлу, ТОГДА новый ответ проходит через окно ответа.
10. КОГДА файл дополнительно изменён на диске вне duet, ТОГДА эти изменения не принимаются автоматически и действуют существующие гарантии сверки диска.
11. КОГДА ответ проходит через окно и обновился во время чтения, ТОГДА сохраняется существующая защита от принятия устаревшего окна.
