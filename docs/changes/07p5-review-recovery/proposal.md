# Шаг 7p5. Продолжение ревью и отзывчивость

В одной рабочей копии новый чат добавил один файл. Девять остальных файлов задачи остались привязаны к предыдущему ревью. Повторная проверка получала тот же конфликт. Пока хранилище ждало проверку, интерфейс ждал ответов на обычные запросы. Повторные нажатия в редакторе могли создавать копии комментария.

## Сценарии

- КОГДА новый чат продолжает задачу в той же рабочей копии и добавляет файл, ТОГДА duet открывает текущее ревью задачи с новым файлом и сохраняет принятие, версии, комментарии и ответы.
- КОГДА задача уже разделилась между текущим и предыдущим ревью, как в описанном случае, ТОГДА в текущем ревью видна команда переноса файлов из предыдущего. После переноса файлы доступны в текущем ревью с их состоянием. Если идёт редактирование или обработка комментариев и перенос сейчас небезопасен, duet показывает конкретную причину и действие для восстановления.
- КОГДА проверка ждёт систему контроля версий, ТОГДА доступные документы открываются, а комментарии сохраняются. Результат проверки применяется к состоянию, для которого он всё ещё действителен.
- КОГДА пользователь нажимает «Проверить снова», ТОГДА он сразу видит ход проверки, а по завершении видит результат и причину оставшейся неполноты.
- КОГДА запрос сохранения комментария выполняется, ТОГДА повторные нажатия отправляют его один раз, виден ход сохранения, а при ошибке текст остаётся в редакторе.

В этот шаг входит восстановление текущего ревью и проверка сценариев в браузере. Уже созданные копии комментариев остаются доступными владельцу. Полное принятие по-прежнему требует согласованной проверки рабочей копии.

## Проверка

- На временной копии чтение и сохранение комментария завершились, пока провайдер ожидал разрешения продолжить проверку.
- В Chrome перенос сохранил комментарий и открыл перенесённый файл в текущей вкладке. Повторное нажатие при задержанном запросе сохранило один комментарий.
- В живом ревью после переноса проверка подтвердила полноту. Все девять ранее принятых файлов сохранили принятие. Новый файл остался открытым для чтения.
