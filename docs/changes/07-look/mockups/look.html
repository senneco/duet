Импорт заметок

Импорт переносит заметки из старого приложения. Он запускается вручную из настроек.

Импорт переносит заметки, папки и вложения из старого приложения. Он запускается сам при первом входе, а потом — из настроек.

Что переносим

Переносим текст заметок и даты создания. Вложения пока не переносим.

Переносим текст заметок, даты создания и изменения, папки и вложения до 20 МБ каждое.

ЧтоКак
Папкисохраняем вложенность
Тегипревращаем в папки верхнего уровня

Конфликты

Если заметка с таким названием уже есть, импорт сравнивает тексты. Одинаковые — пропускает, разные — сохраняет обе и добавляет к новой «(импорт)».

Владелец видит список таких заметок в конце импорта.
Из списка можно открыть обе версии рядом.

Если заметка с таким названием уже есть, импорт пропускает её и пишет об этом в журнал.

Прогресс

Пока идёт импорт, внизу экрана видна полоса прогресса и число перенесённых заметок. Импорт можно поставить на паузу и продолжить позже.

const BATCH = 200; // заметок за один проходawait importNotes({ batch: BATCH, onProgress });

Ограничения

Импорт работает только с файлами до 50 МБ.

Импорт работает с архивами любого размера, но одно вложение — не больше 20 МБ.

Одновременно идёт только один импорт.

Заметки из корзины не переносятся.
