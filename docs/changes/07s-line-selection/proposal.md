# Выделение строк в режиме «Код»

Номера строк служат для выбора целых строк. При выделении и копировании участвует текст кода.

- КОГДА владелец выделяет несколько строк мышью в тексте, ТОГДА подсвечивается и копируется только текст, без номеров строк и знаков diff.
- КОГДА владелец кликает по номеру, ТОГДА выделяется текст всей строки.
- КОГДА владелец ведёт мышью по номерам, ТОГДА выделяются целые строки от первой до последней включительно, в обоих направлениях.
- КОГДА выделение по номерам начинается в одной из двух колонок, ТОГДА оно остаётся в этой колонке.
- КОГДА строки выделены по номерам, ТОГДА доступны обычные действия с выделением — копирование и комментарий.

Ввод диапазона в поле и изменение редактора в этот шаг не входят.

Владелец согласовал поведение и разрешил перейти к реализации сразу.

В Chrome проверены обычное выделение, клик по номеру, обратное протягивание, копирование и ограничение одной колонкой. Тесты Go и веб-клиента прошли.
