# Графические схемы в документе

## Зачем

Блоки Mermaid сейчас показываются кодом, поэтому схемы приходится расшифровывать вручную. В режиме документа они должны быть наглядными изображениями.

## Поведение

- КОГДА Markdown содержит блок mermaid, ТОГДА в режиме документа показана SVG-схема с читаемыми подписями, аккуратными связями и оформлением в цветах duet.
- Поддерживаются блок-схемы, диаграммы состояний и последовательностей, включая русские подписи.
- Светлая и тёмная темы используют согласованные цвета. Большую схему можно раскрыть для подробного просмотра с увеличением.
- КОГДА схема изменилась, ТОГДА правка остаётся заметной; исходный текст с точными отличиями доступен по раскрытию. Комментарий можно оставить к блоку схемы через его исходник.
- В режиме исходника и редакторе остаётся текст Mermaid.
- КОГДА синтаксис схемы ошибочен, ТОГДА документ продолжает работать, а рядом с исходником показана понятная ошибка.
- Библиотека поставляется вместе с duet; текст документов не отправляется внешним сервисам, интернет для просмотра схем не требуется.

## Границы

Первый шаг — Mermaid. Другие форматы схем добавляются при появлении реальных документов с ними. Отдельные макеты не нужны: оформление берётся из существующего интерфейса, результат проверяется на реальных схемах.

## Проверка

Проверить три типа схем в браузере, обе темы, одну и две колонки, окно ответа, раскрытие исходника и ошибочный синтаксис. Проверить, что отображение не меняет содержание файлов и не скрывает точные отличия.

## Результат

Согласовано владельцем. Подключён Mermaid 12.3.0 локально, с лицензией. Три реальные схемы из ответа проверены без ошибок. В Chrome проверены обе темы, одна и две колонки, увеличение и ошибочный синтаксис; внешних запросов нет. Исходник и подсветка правок проверены тестом клиента. Go-тесты и 33 теста клиента прошли.

После живой проверки исправлен перенос SVG в увеличение: идентификаторы, CSS-селекторы и ссылки на маркеры копируются согласованно. Добавлена браузерная проверка совпадения цветов узлов и связей до и после увеличения и отсутствия дублирующихся id. Реальная схема проверена визуально в увеличении.

По просьбе владельца добавлена итоговая схема над построчным диффом (этот путь отрисовки ранее обходил SVG). Дифф под схемой раскрыт. Окно увеличения центрируется независимо от глобального сброса CSS margin. Проверено тестом итоговой схемы и браузерной проверкой координат окна. 34 теста клиента прошли.
