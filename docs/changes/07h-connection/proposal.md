# Диагностика связи

Исправление одобрено владельцем.

КОГДА поток обновлений оборвался, ТОГДА вкладка проверяет доступность сервера. Если сервер отвечает — показывает переподключение к потоку, если не отвечает — недоступность сервера без утверждения об остановке процесса. Проверка повторяется автоматически. Восстановление потока закрывает сообщение; запоздалая проверка не отменяет восстановление.

Проверено в Chrome: сервер доступен, сервер недоступен, восстановление доступности, восстановление потока во время проверки. 32 теста клиента прошли.
