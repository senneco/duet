# Продолжение правок из чата

Согласовано владельцем: непросмотренный ответ не должен мешать дальнейшим правкам из чата. Новый заход показывает работу, сохраняет предыдущий ответ до завершения и объединяет новые правки с ним либо создаёт новый ответ после принятия предыдущего. Реальные конфликты остаются блокирующими.

Проверки: повторная инструментальная правка при непросмотренном ответе; принятие ответа посреди захода; командная правка с последующим Stop; неизменность текущей версии и базы; существующие проверки редактирования владельцем и остановки.
