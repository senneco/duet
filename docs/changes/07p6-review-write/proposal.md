# Шаг 7p6. Правка файлов после принятия

При проверке полноты duet начал запрещать запись любого файла, зарегистрированного в другом ревью. Этот запрет срабатывает и после принятия файла. В результате историческая принадлежность файла останавливает следующую задачу.

- КОГДА агент правит файл, принятый в другом ревью, ТОГДА duet разрешает запись и переносит файл в текущее ревью с принятой базой, версиями и комментариями. После изменения содержимого новую версию нужно принять.
- КОГДА агент правит файл, принадлежащий другому ревью, но в нём ещё идёт работа, открыт редактор или есть непросмотренный ответ по этому файлу, ТОГДА duet показывает конкретное препятствие и ссылку на ревью.
- КОГДА сбор видит уже принятый файл прошлого ревью, который после принятия не менялся, ТОГДА этот файл сам по себе не блокирует полноту текущего ревью.

## Проверка

Сценарий ядра проверяет два ревью. Неизменившийся файл не блокирует полноту нового ревью. Работа подключённого агента в прежнем ревью даёт конкретное объяснение. После завершения работы правка проходит, принятая база и комментарий сохраняются, а новая версия требует принятия.
