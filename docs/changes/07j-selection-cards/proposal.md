# Выделение ниже карточки

Исправление существующего поведения: выделение ниже комментария сбрасывалось при перемещении абзацев во время расстановки карточек.

КОГДА пользователь выделяет текст выше или ниже карточки, ТОГДА диапазон и возможность оставить комментарий сохраняются после повторной отрисовки карточек. Перед перемещением узлов сохраняются границы DOM Range, после — восстанавливаются на тех же текстовых узлах.

В Chrome проверены обе стороны карточки в одной и двух колонках, четыре повторные отрисовки, видимая подсветка и привязка нового комментария. 34 теста клиента прошли.
