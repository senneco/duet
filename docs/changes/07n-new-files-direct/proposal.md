# Шаг 7n: новые файлы сразу в основном просмотре

## Зачем

Новые файлы без исходной версии скрываются в окне ответа, хотя их можно сразу читать целиком и принимать в основном просмотре. В r85 пять прежних файлов приняты, а два новых доступны только в непросмотренном ответе.

## Предлагаемое поведение

Новый файл без исходной версии не препятствует прямому переносу ответа. Если ответ затрагивает только такие новые файлы и/или уже принятые файлы, он сразу появляется в основном просмотре. У новых файлов базы нет, они требуют явного принятия владельцем.

## Входит

- Расширение правила шага 7l на новые файлы без исходной версии.
- Проверки ядра и интерфейса для двух новых файлов и сочетания нового с принятым.

## Не входит

- Изменение баз и автоматическое принятие файлов.
- Разделение одного ответа между окном и основным просмотром.
- Изменение обработки новых файлов с исходной версией.
- Автоматический перенос ранее накопленных непросмотренных ответов.

## Сценарии

1. КОГДА ответ добавляет два новых файла без исходной версии, ТОГДА оба сразу доступны в основном просмотре целиком, без базы; каждый требует принятия, отдельного окна ответа нет.
2. КОГДА ответ сочетает такие новые файлы с изменениями принятых файлов, ТОГДА весь ответ сразу становится текущим; прежние базы сохраняются.
3. КОГДА ответ также меняет существующий непринятый файл, ТОГДА весь ответ остаётся в окне ответа по прежним правилам.
4. КОГДА до начала работы уже был непросмотренный ответ, ТОГДА продолжение накапливается в нём по прежним правилам.
5. КОГДА владелец принимает новый файл, ТОГДА только это действие создаёт его принятую базу.

## Статус

Подтверждено владельцем. Реализовано; требования перенесены в действующие спецификации.
