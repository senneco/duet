# Выделение в одной колонке

Владелец сразу одобрил исправление без уточнений.

КОГДА выделение начинается в одной стороне двухколоночного сравнения, ТОГДА подсветка и копируемый текст содержат только эту сторону. Протягивание не переносит конец выделения в противоположную колонку. Одна колонка сохраняет прежнее поведение.

В Chrome проверены многострочные диапазоны слева и справа: подсветка ограничена выбранной стороной, копируемый текст не содержит другую сторону и номера строк.
