# Редактор на месте текста

## Зачем

При открытии редактора длинная строка растягивается на всё окно, выбранный текст меняет положение. Нужно уменьшить скачок между чтением и правкой.

## Поведение

- КОГДА открывается редактор в одну колонку, ТОГДА ширина и горизонтальное положение области текста соответствуют области чтения.
- КОГДА чтение идёт в две колонки, ТОГДА область текста редактора занимает правую колонку с той же шириной.
- КОГДА есть выделение, ТОГДА оно переносится в исходник и по возможности остаётся на прежней высоте экрана.
- КОГДА выделения нет, ТОГДА ориентиром становится текст около середины видимой области; этот текст по возможности остаётся на прежней высоте.
- Если выравнивание невозможно из-за границ документа или разницы исходника и отформатированного текста, выбирается ближайшее доступное положение.

Редактор остаётся редактором исходника, с существующими шрифтом, подсветкой и командами. Новые элементы управления не добавляются.

## Причина

У редактора собственные отступы и ширина на всё окно. При открытии восстанавливается строка у верхнего края; точное положение выделения внутри перенесённой строки не учитывается. Поэтому даже найденная верная строка не сохраняет положение выбранного слова.

## Проверка

В браузере: выделенное слово внутри длинного абзаца, открытие без выделения, одна и две колонки, разная ширина окна; проверить ширину текста и вертикальное положение ориентира.

## Результат

Владелец согласовал поведение. В Chrome проверены одна и две колонки с выделением слова внутри длинного абзаца и без выделения. Ширина совпала с отклонением до пикселя, высота ориентира — менее пикселя. Исходник и подсветка используют одинаковые размеры и переносы.
