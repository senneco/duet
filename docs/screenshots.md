# Скриншоты прошлой версии

Код прошлой версии потерян вместе с ноутбуком. Остались только скриншоты: `~/Yandex.Disk.localized/Скриншоты/`, файлы с 2026-09-16 по 2026-10-28. В этой папке есть и посторонние скриншоты — фильтруй по датам и содержимому.

Это скриншоты двух версий: первую писали без плана, вторую — по требованиям, с ядром и макетами. Скриншоты делались, чтобы показать агенту проблемы:

- **красные стрелки, рамки, зачёркивания** — то, что не нравилось;
- остальное на тех же скриншотах часто, наоборот, нравилось, и его стоит сохранить.

Что видно на скриншотах:

- отличия в две колонки с заштрихованными пустыми местами и в одну колонку с метками «КАК БЫЛО» / «НОВОЕ», подсветка изменённых слов внутри строки;
- режимы «документ» (отрисованный markdown) и «исходник», подсветка синтаксиса в коде;
- дерево файлов: «принято N из M», статусы (принят ✓, не просмотрен ○, изменён ●, удалён), важность ⇈ ↑ ↓, блоки агента под открытым файлом;
- меню выделения: «Комментарий `gc`», «Копировать `⌘C`»; окно комментария с цитатой выделения, вставкой картинки и кнопками отмена/сохранить; карточки комментариев справа с номером и статусом «не отправлен»;
- карточка «ОТВЕТ АГЕНТА» и записка агента в начале файла;
- панель «Вид»: характер (Тихий / Обычный / Сочный / Яркий), палитры (Сияние, Море, Лес, Закат, Классика), схема (как macOS / тёмная / светлая), края текста, шрифт с засечками, размер текста, фокус по блокам, клавиши на кнопках;
- меню `␣`: a — принять, s — отправить все, e — править, u — отменить, R — повторить, r — открыть ответ.

Используй их на шаге 7 (вид) и при обсуждении любых деталей интерфейса.
