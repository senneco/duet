# Отложено и отклонено

- **Оглавление по заголовкам (outline).** Отклонено в прошлой версии: спорит с блоками агента — две навигации по одному файлу. Вернуться, если в длинных файлах без блоков не хватит навигации.
- **Собственные уведомления.** Отклонено в прошлой версии: оповещения уже есть у терминала и приложения агента.
- **Размытие (стекло) под панелями.** Отклонено в прошлой версии: панели и окна мигали.
- **«Отменить» и «Повторить» в окне ответа.** Отклонено на шаге 2: владелец ими не пользовался. Вместо них есть «отклонить ответ».
- **Отозвать один отправленный комментарий.** Отклонено на шаге 2: лишняя сложность. Есть «прервать» целиком или новый комментарий «не надо».
- **Отклонить ответ по одному файлу.** Отложено на шаге 2: ответ отклоняется только целиком. Вернуться, если часто нужно отклонить один файл из нескольких.
- **Вернуть к базе часть файла.** Отложено на шаге 2: только файл целиком.
- **Закрывать комментарии руками.** Отклонено на шаге 2: комментарии закрываются сами, когда файл принят.
- **Смотреть и принимать ответ, пока агент работает дальше.** Отклонено на шаге 2: появляются цепочки ответов и двоякость, к какой версии относится комментарий.
- **Отправлять комментарии прямо из окна ответа.** Отклонено на шаге 2: сначала принять ответ, потом отправить как обычно — так комментарий всегда относится к текущей версии.
- **Просмотр старых версий в интерфейсе.** Отложено на шаге 2: ядро хранит всю историю, но в интерфейсе только «база → текущая» и окно ответа.
- **Несколько агентов в одном ревью одновременно.** Отклонено на шаге 2: в ревью работает не больше одного агента.
- **Снять файл с ревью.** Отклонено на шаге 3: непринятые правки остались бы на диске мимо ревью и попали бы, например, в коммит. Агент может только удалить файл.
- **Архив ревью.** Отклонено на шаге 3: ревью всегда в списке. Вернуться, если список станет слишком длинным.
- **Один файл в нескольких ревью.** Отклонено на шаге 3: два агента правят один файл, появляются цепочки ответов. Файл переходит в новое ревью целиком.
- **Отправлять комментарии без подключённого агента.** Отклонено на шаге 3: непонятно, кто и чего «ожидает». Без агента duet сразу говорит «нет агента».
- **Автоматически прерывать работу, когда агент пропал.** Отклонено на шаге 3: при прерывании перезаписываются файлы на диске, это делается только по команде владельца.
