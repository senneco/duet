# Отложено и отклонено

- **Оглавление по заголовкам (outline).** Отклонено в прошлой версии: спорит с блоками агента — две навигации по одному файлу. Вернуться, если в длинных файлах без блоков не хватит навигации.
- **Собственные уведомления.** Отклонено в прошлой версии: оповещения уже есть у терминала и приложения агента.
- **Размытие (стекло) под панелями.** Отклонено в прошлой версии: панели и окна мигали.
- **«Отменить» и «Повторить» в окне ответа.** Под вопросом: владелец ими не пользовался. Решить на шаге 3.
