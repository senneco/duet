# Ядро duet

Go, пакет `core`. Хранит ревью, версии файлов, базы и ответы агента и обеспечивает гарантии из `docs/vision.md`.

- Всё состояние лежит в одном `state.json` в папке данных (`~/.duet`). Запись атомарная: пишется временный файл, потом переименовывается.
- Версии файла хранятся навсегда. База, текущая версия и версии из ответа — это номера версий.
- «Принят» не хранится отдельно, а вычисляется: текущая версия совпадает с базой.
- Ответы агента, включая отклонённые и прерванные, лежат в истории ревью.
- Комментарии лежат в файле и переходят вместе с ним в другое ревью. Удалённые и решённые не стираются.
- Привязка комментария хранится как место (байты) в конкретной версии. Когда текущая версия меняется, место переносится по отличиям строк (`diff.go`, алгоритм Майерса).

## Диск (`disk.go`)

- Ядро пишет на диск правку, «вернуть к базе», «отклонить ответ», «перезаписать» и возврат после «прервать». Перед записью (кроме «прервать») проверяет, что на диске ожидаемое; иначе `DiskChangedError` (`errors.Is(err, ErrDiskChanged)`) со списком файлов.
- Ожидаемое — версия из непросмотренного ответа, иначе текущая. Расхождения («изменён на диске») держатся только в памяти: `drift`, путь → что на диске.
- Ревью сверяется с диском при первом действии с ним после запуска (`touch` в `commit`) или по `Sync` (с прогрессом). Дальше `Poll` / `Watch(interval)` перечитывает только файлы, у которых поменялся отпечаток (время, размер). Не следим, пока агент работает или останавливается, и в ревью, принятом целиком (если в нём нет расхождений).
- «Прервать» ставит `Stopping`; диск возвращается в `AgentStopped`, `RestoreAnyway` или `Disconnect`, а если агента нет — сразу.
- Сообщения агенту (`Notice`: файлы, причина, вернувшиеся комментарии) копятся в ревью и забираются `TakeNotices`.
- Диск — интерфейс `Disk`; `nil` — у файлов нет диска. Старые тесты так и работают (выдуманные пути), тесты диска (`disk_test.go`) — на настоящих файлах во временной папке.

## Отличия (`worddiff.go`, `diff.go`)

- `FileDiff` — «база → текущая», `ResponseDiff` — «текущая → ответ», `DiffText` — два любых текста. Результат — куски: `same`, `changed` (старые и новые строки с подсветкой `Marks` внутри), `deleted`, `added`. `Break` у строки — изменён сам перевод строки. Клиент только рисует; соседние куски `changed`/`deleted`/`added` в одной колонке можно показывать одним блоком «было / стало».
- Сначала отличия по строкам (Майерс, линейная память, с лимитом шагов: не хватило — участок переписан целиком). Внутри изменённых участков — по токенам (слова, пробелы, знаки), сначала по опорам — токенам, которые встречаются по одному разу в обеих версиях (как patience diff), потом Майерс.
- Затем правила показа: склейка правок без дыр, абзац и предложение «переписано больше чем наполовину», сведение строк в пары по общим словам, строка кода «больше чем наполовину». Доли считаются по реальным правкам до склейки. Пороги — константы в начале `worddiff.go`.
- Текст или код — по расширению (`IsProse`); блоки ``` в markdown — код. В тексте перевод строки внутри абзаца равен пробелу.
- Главная проверка — `TestDiffEveryChangeVisible`: на тысячах случайных правок всё неподсвеченное совпадает в обеих версиях и между подсветками в строке нет дыр из пробелов.

Сборка и тесты: `go test ./...` из корня репозитория (нужен Go 1.27+, `brew install go`).
